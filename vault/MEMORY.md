### Платформы и инструменты

- **Blender** — планировщик коммуникаций, конкурируем за слоты (банк → НФС → сервисы)
- **Kaen** — DSP для запусков, настройка сценариев
- **T-Segments** — сегментация аудитории (ключевой инструмент для персонализации)
- **Touch** — новая платформа, должна снизить ТТМ (ещё полгода до эффекта)
- **Hippo** — гипотезы/инициативы
- **Statist** — статистика тестов

### Бизнес-контекст XSell

**Масштаб:** ~240 запусков/мес, ~15 млрд показов баннеров/мес, ~2 млрд пушей/мес, ~22% Shopping доля
**Конкуренция в Blender:** банк → НФС (уровень 1), сервисы между собой (уровень 2)
**Главная боль:** Трафик. Внешка не выросла. Базу выжигаем, CTR низкий, конкуренция между сервисами внутри
**Процессные проблемы:** ТТМ слишком длинный (тред → Jira → выборка → преданализ → запуск); ручная работа выборок; нет предпланирования

**Регламенты** — автозапуски на кроне (Kaen + цепочки), требуют поддержки
**Цепочки новичков** — клиент в банк → звено 1–2–3 → офферы. Нужна автоматизация
