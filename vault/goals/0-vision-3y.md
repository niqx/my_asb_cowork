**3-Year Vision:**
Руководитель аналитики уровня TL3 (руководитель руководителей). Трансформировать аналитическую команду из операционной в стратегическую — от «запускаторов» к «партнёрам бизнеса». Заниматься интересным проектом в комфортной компании с реальным влиянием на бизнес-результат.

**Key Milestones:**
- [x] Перейти в подходящую компанию — XSell Шопинг, Т-банк ✅ (2026)
- [x] Стать TL3 — руководитель руководителей ✅ (2026)
- [ ] Трансформировать команду XSell: TTM ↓, автоматизация, аналитики → партнёры бизнеса
- [ ] Собрать портфель значимых результатов: GMV-инкремент, снижение ручного труда, AI-инструменты
- [ ] Сформировать сильную команду: закрытые лиды, ИПР, кросс-направленческое переопыление
